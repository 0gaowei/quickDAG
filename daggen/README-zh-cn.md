# DAGGEN：一个合成任务图生成器

## 第一种格式：直观的文件格式

这个程序生成随机的合成任务图，用于仿真目的。例如，可以用来评估需要在广泛应用配置范围内测试的调度算法。

程序输出文件以两种不同格式描述DAG（有向无环图）的节点集合。首先，我们定义一个直观的文件格式，基本的行格式如下：

```bash
NODE <索引> <子节点列表> <节点类型> <节点成本> <并行化开销>
```

节点可以有四种类型：

- **ROOT**：一个唯一的人工入口节点，成本为零，没有前驱节点，并且以DAG的入口节点作为后继节点。
- **COMPUTATION**：一个计算任务由索引、子节点列表（传输到依赖任务）、顺序成本（以Flop为单位），以及一个额外的参数定义，可以用于其他目的。例如，我们使用该参数来编码任务的并行化开销（如阿姆达尔定律中的α参数）在并行任务图中的作用。
- **TRANSFER**：一个通信任务由索引、一个子节点（接收任务）和数据量（以字节为单位）定义。
- **END**：一个唯一的人工退出节点，成本为零，没有后继节点，并且以DAG的退出节点作为前驱节点。

## 第二种格式：DOT格式

第二种可用格式是流行的DOT格式。通过在命令行中添加 `--dot` 标志来激活此输出格式。在这种格式中，不会生成虚拟的“ROOT”和“END”节点。COMPUTATION的基本行格式是：

```bash
<索引> [size="<节点成本>", alpha="并行化开销"]
```

而TRANSFER的基本格式是：

```bash
<src_index> -> <dst_index> [size ="<节点成本>"]
```

## 参数

DAGGEN通过以下常见参数生成任务图：

- `--n`：DAG中计算节点的数量（即应用程序“任务”）
- `--mindata`：任务处理的数据的最小大小
- `--maxdata`：任务处理的数据的最大大小
- `--minalpha`：额外参数（例如阿姆达尔定律参数）的最小值
- `--maxalpha`：额外参数（例如阿姆达尔定律参数）的最大值
- `--fat`：DAG的宽度，即最大并发执行的任务数量。较小的值会导致一个瘦DAG（例如链式结构），具有较低的任务并行性，而较大的值会导致一个胖DAG（例如叉-连接结构），具有较高的并行度。
- `--density`：决定两个连续DAG级别之间任务依赖的数量。
- `--regular`：DAG中不同级别任务分布的规律性。
- `--ccr`：通信与计算的比率。在当前版本中，该参数实际上仅编码任务计算的复杂度，具体取决于数据集中的元素数量（如果任务处理的是n个元素）。元素数量依赖于任务处理的数据量。编码方式如下：
  - 1：a . n（a是一个随机选择的常数，取值范围在26到29之间）
  - 2：a . n log n
  - 3：n^3/2
  - 0：从三个复杂度中随机选择
- `--jump`：任务间通信所跨越的最大级别数。此参数允许生成具有不同执行路径长度的DAG。

## DAGGEN通过以下过程生成随机DAG

1. **生成任务**
   - a) 根据`-n`和`--fat`参数的值，确定DAG中每个级别的完美任务数量：e fat * log(n)
   - b) 根据`--regular`参数为每个级别分配任务数。以完美值为基础，随机选择一个值，允许有（100 *(1 - regular)）%的偏差。例如，如果`regular`为0.2，则任务数量将在[0.2* 完美值；1.8 * 完美值]范围内选择。
   - c) 为每个任务分配一个成本。这个成本依赖于`--mindata`、`--maxdata`（用于确定任务处理的数据大小）和`--ccr`。
   - d) 在`--minalpha`和`--maxalpha`之间随机选择一个`alpha`值。

2. **生成依赖关系**：对于每个任务，根据`--density`随机分配一个父节点数量。给定任务的父节点数通过以下公式计算：

   ```bash
   MIN(1 + 随机(0, density * 上一层任务数量), 上一层任务数量)
   ```

   `--jump`参数允许生成器选择在某个级别上“跳跃”的父节点。每个父节点然后在选定的级别中随机确定。

3. **添加传输成本**：这些成本源自传输发起方处理的数据大小。

## 具体示例

### 生成 DAG 图的步骤

1. **运行程序生成 DAG**：
   使用以下命令运行程序并指定生成输出文件：

   ```bash
   ./daggen -o output_file.txt
   ```

   这会使用程序生成一个 DAG，并将其输出到 `output_file.txt` 文件中。如果想要以 DOT 格式输出（便于图形化工具生成图像），可以使用 `--dot` 选项。

   例如：

   ```bash
   ./daggen -o output_file.txt --dot
   ```

2. **解析生成的 DOT 文件**：
   程序将生成一个 DOT 格式的 DAG 文件，接下来可以使用工具如 **Graphviz** 来将其可视化为图形。

   例如，使用 Graphviz 工具生成图像：

   ```bash
   dot -Tpng output_file.txt -o dag_graph.png
   ```

   这会将 `output_file.txt` 文件中的 DOT 图生成并保存为 `dag_graph.png` 图片。

3. **查看结果**：
   可以使用任何支持 PNG 格式的图像查看器打开 `dag_graph.png`，查看生成的 DAG 图。

### 额外提示

- 可以通过调整程序的参数（如节点数、稀疏度等）来生成不同的 DAG 结构。例如，调整 `-n` 来控制节点数，调整 `--density` 来控制图的密度等。
  
  示例：

  ```bash
  ./daggen -n 200 --density 0.5 --dot -o output.dot
  ```

  然后使用 Graphviz 生成图像：

  ```bash
  dot -Tpng output.dot -o dag_graph.png
  ```
